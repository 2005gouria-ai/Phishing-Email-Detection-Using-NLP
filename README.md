# 🛡️ Phishing Email Detection Using NLP

An end-to-end Machine Learning and Natural Language Processing (NLP) project designed to automatically detect and classify phishing emails from legitimate ones.

## 📌 Project Overview
Phishing attacks are a major cyber threat. This project utilizes text preprocessing, feature extraction (such as TF-IDF or Word Embeddings), and machine learning/deep learning classification algorithms to analyze email content and identify malicious intent before it reaches the user.

## 🚀 Features
* **Text Preprocessing:** Cleans raw email text (removes HTML tags, punctuation, stopwords, and performs stemming/lemmatization).
* **Feature Extraction:** Converts text into numerical vectors using techniques like Bag-of-Words, TF-IDF, or Word2Vec.
* **Classification Models:** Implements and compares multiple algorithms (e.g., Naive Bayes, Logistic Regression, Random Forest, or LSTM).
* **Evaluation Metrics:** Evaluates model performance using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
